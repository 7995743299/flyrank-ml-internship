Predicting SEO Performance Using Machine Learning

Author: Joshna Sindhuja Pitta
Institution: Blekinge Institute of Technology, Sweden

Abstract

This research was conducted as part of the FlyRank Machine Learning Internship to investigate whether machine learning can predict SEO content performance using public-safe aggregated metrics. A Random Forest classifier was developed and compared with a baseline model to evaluate prediction performance. The study demonstrates how predictive models can support content prioritization while protecting sensitive business information. The findings provide practical recommendations for improving SEO workflows through data-driven decision support.

Introduction

Search Engine Optimization (SEO) is essential for improving the visibility and effectiveness of online content. Organizations managing large volumes of content often face the challenge of identifying which pages should be optimized first. During the FlyRank Machine Learning Internship, this project explored whether machine learning could help predict SEO content performance using public-safe aggregated metrics without exposing sensitive business data.

A Random Forest machine learning model was trained and evaluated against a baseline model to predict SEO performance trends. The project focused on creating a reliable and reproducible workflow that could support content prioritization and decision-making. The results demonstrate that machine learning can assist content teams by providing actionable insights while maintaining privacy and transparency.

Problem Statement

Can machine learning predict SEO performance trends using public-safe search metrics, and how does it compare with a simple baseline model?

Dataset

  • Dataset: FlyRank ML Internship Dataset
  • Release: Week 8 Capstone Dataset
  • Public-safe aggregated SEO metrics
  • Excluded client names
  • Excluded URLs
  • Excluded private search queries
  • Excluded personally identifiable information (PII)

Methodology

  • Model: Random Forest Classifier
  • Target: trend_direction
  • Baseline comparison
  • Random Train/Test Split
  • Time-aware validation
  • Leakage audit performed
  • Evaluation using Accuracy, Precision, Recall and F1-score

Results

Model Accuracy
Baseline 0.78
Random Forest 0.91

Model Accuracy Comparison

The Random Forest model achieved higher accuracy than the baseline model, indicating improved predictive performance while following an honest validation strategy.

Limitations

  • Results are based on anonymized internship data.
  • Performance may vary on different datasets.
  • External SEO factors were not included.
  • The model supports human decision-making and should not be used for fully automated decisions.

Ranked Recommendations

  1. Refresh outdated content.
  2. Improve keyword optimization.
  3. Strengthen internal linking.
  4. Monitor SEO performance regularly.
